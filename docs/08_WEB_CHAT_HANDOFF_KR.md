# 웹사이트 개발 별도 채팅 인계서

**이 저장소의 현재 범위는 운영 모드 및 인프라 설계다.** 다른 채팅의 웹 UI 개발은 다음 사실을 전제로 한다.

- Raspberry Pi 5 8 GB, microSD 512 GB, SSD 1 TB.
- 로봇 BMO와 서버 앱은 동시에 구동하지 않는다.
- 개인 파일/관리 기능은 비공개 Tailscale만; Cloudflare Tunnel은 별도 승인된 공개 사이트에 한정.
- 서버 모드가 아니면 Pi의 동적 웹 서비스는 오프라인이다.
- 항상 공개되어야 하는 포트폴리오는 GitHub Pages 등의 별도 정적 호스팅을 사용한다.
- 사용자 요청에 따라 웹 화면 및 포트폴리오 개발은 **별도 채팅에서만** 진행하며 이곳에는 서버 인프라 공통 규격/배포 연결 방법만 반영한다.
- UI 코드는 BMO R10 얼굴 및 실제 로봇 API/비밀키를 무단으로 건드리지 않는다.
- 웹 앱이 만들어지면 이 저장소에 배포 명세(필요한 포트, 데이터, 권한, 리소스 제한)를 문서화하고, 보안 검증 후 모드 시스템에 연결한다.
